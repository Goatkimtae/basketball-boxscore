# HoopStat 사용법

농구 경기 영상을 넣으면 **야투 시도와 성공을 자동으로 찾아** 팀별 박스스코어를 만듭니다.
리바운드·어시스트·파울·턴오버·자유투·등번호는 화면에서 직접 넣거나 고칩니다.

## 설치

1. `HoopStat.exe`를 원하는 폴더에 둡니다. 설치 과정은 없습니다.
2. 처음 실행할 때 Windows가 "PC 보호" 창을 띄우면 **추가 정보 → 실행**을 누릅니다.
   (서명하지 않은 프로그램이라 뜨는 경고입니다.)

## 순서

1. **경기 영상**: `찾아보기…`로 mp4 등 영상을 고릅니다.
2. **체육관 설정**: 처음 가는 체육관이면 `새로 만들기(골대 표시)…`
   - 막대를 움직여 왼쪽 골대가 보이는 장면을 찾고 **림(고리) 한가운데**를 누릅니다.
   - '오른쪽 골대'로 바꿔 오른쪽 골대 림을 누릅니다.
   - 이름을 정하고 저장합니다. 같은 체육관 영상은 다음부터 이 설정을 고르기만 하면 됩니다.
3. **팀**: 왼쪽 골대를 공격하는 팀과 오른쪽 골대를 공격하는 팀의 이름·색을 적습니다.
   후반에 방향이 바뀌면 바뀌는 시각(영상 기준 초)을 적습니다.
4. **분석 시작**: 진행 막대가 끝나면 '사건 기록' 표에 야투가 나옵니다.
   - 개발 환경(4코어 CPU)에서 92초 영상에 약 1분 40초 걸렸습니다. 8분 영상은 9분 안팎으로 예상합니다(PC 성능에 따라 다름).
5. **검토**
   - 줄을 고르고 `장면 보기`로 앞뒤 장면을 확인합니다.
   - 줄을 두 번 누르면 수정합니다(3점슛, 성공/실패, 등번호).
   - `사건 추가…`로 리바운드·어시스트·스틸·블록·턴오버·파울·자유투를 넣습니다.
   - '박스스코어' 탭에서 팀·선수별 합계를 확인합니다.
6. **저장**: 엑셀, 웹페이지(HTML), CSV로 저장합니다. `작업 저장`으로 저장해 두면 나중에 이어서 고칠 수 있습니다.
   - 웹페이지 파일을 GitHub Pages 저장소에 `index.html`로 올리면 링크로 공유할 수 있습니다.

## 자동 판정 방식과 한계

| 항목 | 방식 | 한계 |
|---|---|---|
| 골대 위치 | 체육관 설정의 골대 그림과 같은 곳을 매 장면 찾음(카메라가 움직여도 됨) | 다른 체육관은 설정을 새로 만들어야 함 |
| 야투 시도 | 골대 근처에서 주황색으로 움직이는 공이 림 높이 이상 올라간 구간 | 공이 화면 밖일 때 던진 슛은 못 찾음. 색이 다른 공·조명에서는 놓칠 수 있음 |
| 성공/실패 | 공이 림 바로 위에서 0.6초 안에 림 가운데 아래로 지나가면 성공 | 그물이 가려지거나 흐리면 성공을 실패로 볼 수 있음 |
| 팀 | 공격하는 골대 방향으로 정함 | 방향이 바뀌는 시각을 적어야 함 |
| 2점/3점 | 자동은 모두 2점 | 3점은 직접 바꿔야 함 |
| 자유투 점수 | 팀 규칙: 슈팅 파울은 자유투 1개. 성공 시 2점슛 파울 2점, 3점슛 파울 3점. 앤드원 1점 | |

92초 샘플 한 개로 맞춘 규칙이라, 다른 영상에서는 반드시 `장면 보기`로 확인하세요.
'신뢰도'가 낮은 줄부터 보면 빠릅니다.

## 체육관 설정이 저장되는 곳

`%APPDATA%\HoopStat\profiles\<체육관 이름>` (left.png, right.png, profile.json)
